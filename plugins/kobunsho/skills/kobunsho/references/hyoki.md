# 表記の細目

「公用文作成の考え方」（令和4年1月7日 文化審議会建議。以下「建議」という。）の「Ⅰ 表記の原則」と、その解説から、開発文書で使う部分を抜き出した。各項目の末尾に建議の該当箇所を示す。

## 1 仮名で書く語

常用漢字表に使える漢字があっても、次の語は仮名で書く。（解説 Ⅰ-1(3)）

| 種類 | 仮名で書く | 漢字で書く場合 |
|---|---|---|
| 助詞 | など（例示）、くらい（程度）、ほど（程度） | 「等」は「とう」と読むときに使う |
| 助動詞 | 〜のようだ、（やむを得）ない | |
| 補助的な用法 | 〜ていく、〜ていただく、〜てくださる、〜てくる、〜てみる、〜てほしい、〜てよい | 実際の動作・状態を表す場合（街へ行く、賞状を頂く、東から来る、しっかり見る、資格が欲しい、声が良い） |
| 形式名詞 | こと、とき、ところ、もの、うち、ため、とおり、ゆえ、よう、わけ | 具体的に特定できる対象がある場合（事は重大である、法律の定める年齢に達した時、家を建てる所、所持する物、裁判所の指名した者、内に秘める、大通り、故あって、訳あって） |
| 指示代名詞 | これ、それ、どれ、ここ、そこ、どこ | |
| 意味が薄くなった語 | ありがとう、おはよう、こんにちは、逆さま | 有り難い |
| 当て字・熟字訓 | いつ、いかん、思わく、さすが、すばらしい、たばこ、ちょっと、ふだん、めった | 常用漢字表の付表にある語 |
| その他 | 〜するとともに | 彼と共に |
| 接続詞 | さらに、しかし、しかしながら、したがって、そして、そうして、そこで、それゆえ、ただし、ところが、ところで、また | 及び、又は、並びに、若しくは。副詞の「更に」「又」、動詞の「従う」 |
| 連体詞 | あらゆる、ある（〜日）、いかなる、いわゆる、この、その、どの | 来る（きたる）、去る、当の、我が |
| 接頭辞・接尾辞 | お（お願い）、〜げ、〜とも（二人とも）、〜たち、〜ら、〜ぶる、〜ぶり、〜み | 「御（おん・ご）」は漢字（御礼、御意見）。表外漢字を含む語は「御」も仮名（ごちそう、ごもっとも） |
| 動詞 | いる、できる（利用ができる）、なる（1万円になる） | 出来が良い、歩が金に成る、本表と付表から成る |
| 副詞 | いろいろ、おおむね、おのずから、いかに、いずれ、かなり、ここに、たくさん、ちょうど、とても、やがて、よほど、わざと、わざわざ | 既に、直ちに、正に、余り、飽くまで、幾ら、何分 |
| ある・ない | 問題がある、欠点がない | 有無を対照させる場合、所在・存在を強調する場合（財産が有る、有り・無し、在り方、日本はアジアの東に在る） |
| 法令に倣う語 | おそれ（虞）、かつ（且つ）、ただし（但し）、ただし書、ほか（外・他）、よる（因る） | |

## 2 常用漢字表で書けない語

表外漢字・表外音訓を含む語は、次のいずれかで書く。（解説 Ⅰ-1(2)）

1. 訓による語は平仮名で書く。
   - 敢えて → あえて、予め → あらかじめ、或いは → あるいは、概ね → おおむね、叶う → かなう、捗る → はかどる、宜しく → よろしく
2. 音による語でも、漢字を使わずに意味が通じるものは平仮名で書く。
   - 斡旋 → あっせん、杜撰 → ずさん、咄嗟 → とっさ
3. 同じ訓・同じ音を持ち、意味の通じる常用漢字で書く。
   - 活かす → 生かす、解る・判る → 分かる、手許 → 手元、車輛 → 車両、編輯 → 編集
4. 常用漢字を使った別の言葉に言い換える。
   - 軋轢 → 摩擦、捺印 → 押印、逼迫 → 切迫、漏洩する → 漏らす、脆弱な → 弱い、もろい
5. 言い換えると不都合なものは、表外漢字だけを仮名にするか、振り仮名を付ける。
   - 改竄 → 改ざん、牽引 → けん引、招聘 → 招へい
   - 振り仮名が使えない Markdown などでは、括弧で読みを示す（招聘（しょうへい））。初出だけでよい。

開発文書でよく見かける語の例を挙げる。

| 書かない | 書く |
|---|---|
| 紐付け、紐づけ | ひも付け、ひもづけ |
| 齟齬 | 食い違い |
| 揃える | そろえる |
| 繋ぐ、繋がる | つなぐ、つながる |
| 纏める | まとめる |
| 辿る | たどる |
| 掴む | つかむ |
| 溜まる、溜める | たまる、ためる |
| 嵌まる、嵌める | はまる、はめる |
| 覗く | のぞく |
| 馴染む | なじむ |
| 雛形 | ひな形 |
| 綺麗 | きれい |
| 筈 | はず |
| 迄 | まで |
| 脆弱性 | 脆弱（ぜいじゃく）性、又はぜい弱性（専門用語として言い換えない） |

字体は常用漢字表の通用字体を使う。「填、頬、剥」ではなく「塡、頰、剝」と書く（補塡、頰、剝離）。（解説 Ⅰ-1(1)イ）

## 3 送り仮名

「送り仮名の付け方」（昭和48年内閣告示第2号）の本則と例外に従う。（解説 Ⅰ-2）

- 本則で書く：行う（行なう は使わない）、表す、現れる、断る、終わる、押さえる、捕らえる

## 4 外来語

「外来語の表記」（平成3年内閣告示第2号）に従う。（解説 Ⅰ-3）

- 日本語として広く使われている表記を使う（デジタル、プラスチック）。
- 長音は長音符号で書く。英語の -er、-or、-ar に当たる語末は長音符号を付ける（コンピューター、エレベーター、サーバー、ユーザー、フォルダー、パラメーター、ブラウザー、エディター）。
- -ty、-ry で終わる語も長音符号を付けるのが原則である（コミュニティー、カテゴリー）。開発分野では「リポジトリ」「ディレクトリ」のように付けない慣用もあるため、プロジェクトの表記が決まっていればそれに従い、文書の中で統一する。
- 「ヴ」はむやみに使わず、バ行で書く（バイオリン）。
- 第1表と第2表のどちらに基づくか（ウイルス／ウィルス）は、文書の中で統一する。

## 5 数字

横書きの数字の書き方。（建議 Ⅰ-4、解説 Ⅰ-4）

- 算用数字を使う（令和2年11月26日、午後2時37分、72％）。
- 四桁以上は三桁ごとにコンマで区切る（5,000、1,254,372人）。
- 兆・億・万は漢字で書く。千・百は漢字にしない（5兆100億30万円、5,000）。
- データや金額などの数値は半角で書く。全角と半角を混ぜない。
- 漢数字を使うもの
  - 概数：二十余人、数十人、四、五十人（算用数字にそろえたい場合は「20人余り」「40〜50人」）
  - 熟語・成語：二者択一、三日坊主、再三再四
  - 常用漢字表の訓による数え方：一つ、二つ、一人、二人、一日（ついたち）
  - 他の数字と置き換えられない数：三権分立、七福神
- 「3か所」「7か月」と書く。「ヶ」「カ」は使わない。概数や漢数字では「数箇所」「三箇月」と書く。
- 期間の数え方：満5年、5か年、5年ぶり、5周年はまるまる5年。5年目、5年越しは起算の年を含む。

## 6 符号

（建議 Ⅰ-5、解説 Ⅰ-5）

- 句点は「。」、読点は「、」。横書きで「，」を使う場合は、文書の中で混ぜない。句点に「．」は使わない。
- 「・」は、並列する語（赤・緑・青）、外来語や人名の区切り（ケース・バイ・ケース）に使う。
- 括弧は（）と「」を基本とする。入れ子でもそのまま重ねる。
  - 「「異字同訓」の漢字の使い分け例」（平成26（2014）年）
- 括弧の中で文が終わる場合は句点を打つ。引用、語句、名詞で終わる場合は打たない。
  - （以下「基本計画」という。）、「決める。」と発言した。
  - 議事録に「決める」との発言があった。国立科学博物館（上野）
- 文末の括弧が部分的な注釈なら、閉じ括弧の後に句点を打つ。二つ以上の文や文章全体の注釈なら、最後の文の句点の後に括弧を置く。
  - ただし、年内にも再開を予定している（日程は未定である。）。
  - ただし、年内にも再開を予定している。（別紙として、経緯に関する資料を付した。）
- 【】は項目を示したり、強調したい点を目立たせたりするときに使う（【会場】、【取扱注意】）。
- 「：」「―」「‐」「〜」「…」「※」などは、文書の中で用法を統一し、多用しない。
- 繰り返し符号は「々」だけを使う。複合語の切れ目では使わない（民主主義、○○党党首）。2字以上の繰り返しはそのまま書く（ますます、一人一人）。

## 7 その他

- 日本人の姓名をローマ字で書くときは「姓―名」の順にする（YAMADA Haruo）。（建議 Ⅰ-6オ）
- 略語は、元の語を示してから使う。外国語に基づく略語は、片仮名の正式名称の後に括弧で示す（クオリティー・オブ・ライフ（Quality of Life。以下「QOL」という。））。（建議 Ⅰ-6ク）
- 図表には、内容を一言で表す標題を付ける。（建議 Ⅰ-6ケ）
